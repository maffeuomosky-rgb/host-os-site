# HOST OS Site

Landing page ufficiale di HOST OS 1.2.

## Struttura
- `index.html` — landing page principale
- `styles.css` — stile completo della landing
- `script.js` — interazioni, Product Explorer scroll-driven, linea luminosa e reveal on scroll
- `legal.css` — stile condiviso delle pagine legali
- `termini.html` — Termini e condizioni
- `privacy.html` — Informativa privacy
- `rimborsi.html` — Rimborsi e diritto di recesso
- `LEGAL_DATA_TO_COMPLETE.txt` — dati da inserire prima del checkout
- `assets/` — screenshot e brand asset ufficiali
- `vercel.json` — configurazione deploy statico Vercel
