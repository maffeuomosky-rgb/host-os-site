## Caricamento GitHub
Caricare NELLA ROOT del repository `host-os-site` il CONTENUTO di questa cartella, non la cartella esterna e non il file ZIP.

La struttura deve iniziare direttamente con:
- index.html
- styles.css
- script.js
- legal.css
- termini.html
- privacy.html
- rimborsi.html
- vercel.json
- assets/

Vercel effettuerà il redeploy automaticamente dopo il commit su `main`.
