PROCEDURA CONSIGLIATA — GITHUB WEB

1. Scarica HOST_OS_GITHUB_UPLOAD_READY.zip
2. Estrai lo ZIP sul computer
3. Apri GitHub → maffeuomosky-rgb/host-os-site
4. Vai sul branch main
5. Se il repository contiene una vecchia versione incompleta, sostituisci i file esistenti con quelli di questo pacchetto
6. Usa Add file → Upload files
7. Trascina DENTRO l'area di upload tutti i FILE della root e le CARTELLE:
   api
   assets
   db
   lib
   scripts
   tests
8. Non trascinare la cartella esterna HOST_OS_GITHUB_UPLOAD_READY: devi caricare il suo CONTENUTO nella root
9. Commit message consigliato:
   Deploy HOST OS 1.3.2 checkout payment integrated
10. Premi Commit changes
11. Vercel dovrebbe avviare automaticamente un nuovo deployment se il repository è già collegato

DOPO IL COMMIT
- Controlla che nella root di GitHub ci sia index.html
- Controlla che api/ contenga gli endpoint .js
- Controlla che assets/ contenga immagini e host_os_demo_1_2.mp4
- Controlla che package.json e vercel.json siano nella root
- NON inserire segreti nei file GitHub
